Self-Assessment Exam Simulator

Load a questions PDF and its answer-key PDF to start a timed, exam-style session. Without the answer key the sitting still works; it just isn't scored.

Flat, image-only PDFs (screenshot exports) are recognized automatically in your browser; the first load takes a minute or two.

Default is real-exam pacing (90 sec/question). Set to 0 for an untimed session. The timer turns red near the end but never forces a submit.
